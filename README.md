# لوحة تحكم تفاعلية

لوحة تحكم عربية حديثة مع مميزات متعددة.

## المميزات
- تصميم متجاوب بالكامل
- وضعية طي القائمة الجانبية
- بحث مباشر في الطلبات
- إشعارات تفاعلية
- دعم كامل للغة العربية

## تقنيات مستخدمة
- HTML5
- CSS3
- JavaScript
- Font Awesome 6

## تشغيل المشروع محلياً
1. حمل الملفات
2. افتح `index.html` في المتصفح
